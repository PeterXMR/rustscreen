# Project State

## Project Reference

See: .planning/PROJECT.md (updated 2026-06-02)

**Core value:** Plug a Pixel 6a into an M1 MacBook with one USB-C cable, launch the host, and within seconds get a touch-capable extended display at < 50 ms glass-to-glass.
**Current focus (2026-06-05):** **The live pipeline works** — the Mac desktop renders on the phone end-to-end (P4 Wave B decode-to-surface, P5 live wiring, P2 arrangeable display, and glass-to-glass latency instrumentation + tuning are all MERGED: PRs #20, #21, #22, #23 and commit `48c1b05`). Work is now driven by the **user-set Priorities 1–3 in `.planning/ROADMAP.md` → "Active Priorities" section** (that section is the single source of truth for what to do next; it supersedes the old PR-ladder order):
  1. **`rustscreen` terminal CLI** — installable release binary; `start` runs the host as a background process + auto-streams when the phone app opens; `stop` kills it.
  2. **Auto-reconnect** — `start` is a supervisor loop that re-handshakes on phone-app close/reopen, host restart, or cable replug.
  3. **Native-feel latency** — keep glass-to-glass < 50 ms (next lever: non-blocking USB writes, ~18 ms).
Detailed sub-tasks for all three are in the ROADMAP "Implementation backlog". The three separate research TODO docs were consolidated into ROADMAP and deleted on 2026-06-05.

**Authoritative design source:** `docs/superpowers/plans/2026-06-02-rustscreen-architecture-roadmap.md` (full acceptance criteria, seam table, risk register). This `.planning/` set is the execution tracker.
